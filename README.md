# emojiiiiii

一个无需后端的静态网页 MVP：打开相机，用常见手势匹配聊天表情；表情可复制、收藏、下载为图片或分享。新增“表情陪伴”模式，会在浏览器本地从面部表情中提取有限线索，并给出一句温和回应。

相机目前支持 10 类动作：点赞、倒赞、张开手掌、胜利手势、握拳、食指向上、爱心手势、OK、打电话和三根手指。后三类会结合手部关键点在浏览器本地判断。

## 本地查看

在项目目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。相机功能需要通过 `localhost` 或 HTTPS 打开；直接双击 `index.html` 时，浏览器可能会阻止相机权限。

## 部署到 Vercel

将此文件夹导入 Vercel，框架预设选择 **Other**，无需填写构建命令和输出目录。部署后用 HTTPS 打开，即可允许浏览器访问相机。

## 说明

- 手势和面部表情模型由浏览器从 MediaPipe 的公开资源加载，并在本地处理相机画面。
- “表情陪伴”仅描述可见表情（例如“看起来有些紧绷”），不能判断一个人的真实感受或心理健康状况；它不保存、不上传相机画面。
- 识别器加载失败或设备不支持相机时，仍可通过“选择动作”找表情，或在“表情陪伴”中手动选择状态。
