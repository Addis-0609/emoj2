# emojiiiiii

一个无需后端的静态网页 MVP：打开相机，用常见手势匹配聊天表情；表情可复制、收藏、下载为图片或分享。

## 本地查看

在项目目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。相机功能需要通过 `localhost` 或 HTTPS 打开；直接双击 `index.html` 时，浏览器可能会阻止相机权限。

## 部署到 Vercel

将此文件夹导入 Vercel，框架预设选择 **Other**，无需填写构建命令和输出目录。部署后用 HTTPS 打开，即可允许浏览器访问相机。

## 说明

- 手势识别模型由浏览器从 MediaPipe 的公开资源加载，并在本地处理相机画面。
- 识别器加载失败或设备不支持相机时，仍可从“选择动作”中完成整个表情选择、复制、收藏与导出流程。
